# 교재 표시 대조표

`Photos-1-001` 55장(교재 94~237쪽)을 **표시된 흔적만** 기준으로 다시 훑어 만든 표다.
노트의 강조 등급은 **전부 이 표를 근거로** 매겼다. 내 판단으로 "이건 나올 것 같다"고 붙인 게 아니다.

## 표시 강도 측정 방법

각 장에서 픽셀 단위로 세 가지를 셌다.

| 표시 | 검출 기준 | 의미 |
| --- | --- | --- |
| **연분홍 형광** | R−G 12~50, R>200 | 선생님이 그어준 밑줄·형광 |
| **진한 빨강** | R−G>50, R>120 | 취소선·강한 밑줄 |
| **파란 손글씨** | B−R>40, B−G>25 | 필기 메모 · 별표 · 동그라미 |
