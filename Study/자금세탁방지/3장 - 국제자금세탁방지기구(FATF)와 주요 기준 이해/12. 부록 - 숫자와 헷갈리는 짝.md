# 부록 B. 헷갈리는 짝 비교

| 헷갈리는 것 | 구분 포인트 |
| --- | --- |
| **권고 6 vs 권고 7** | 6 = **테러/TF** (1267·1373) / 7 = **확산금융 PF, WMD** (1718·1737) |
| **STR vs CTR** | STR = **의무**, 금액 무관, **미수거래 포함** / CTR = 실행가능성을 **"고려"** |
| **Tipping-off vs Safe harbor** | 전자 = 보고 사실을 **알리면 안 됨** / 후자 = 선의로 보고했으면 **책임 면제** |
| **제3자 의존 vs 아웃소싱** | 제3자 = 자기 고객관계 + **자체 절차** (권고 17 적용) / 아웃소싱 = 위임기관 절차 + **통제 받음** (권고 17 **미적용**) |
| **외국 PEP vs 국내·국제기구 PEP** | 외국 = **무조건 EDD** / 국내·국제기구 = **위험평가 결과 고위험일 때만 EDD** |
| **명단 삭제 vs 긍정오류 해제** | 전자 = 지정기준 미충족 → 제재위원회·Focal Point·옴부즈퍼슨 / 후자 = **동명이인 오동결** → 별도 해제 절차 |
| **Focal Point vs 옴부즈퍼슨** | Focal Point = **일반 지정해제 청원 접수** / 옴부즈퍼슨 = ==**알카에다 명단 전용**== |
| **운영분석 vs 전략분석** | 운영 = **특정 대상 식별**(개별 사건) / 전략 = **동향·패턴 식별**(정책 수립) |
| **권고 22 귀금속 vs 권고 32 금·귀금속** | 22 = 15,000 현금거래 시 **CDD 대상** / 32 = 국경 반출입 신고 **대상에서 제외** |
| **감독 주체** | 금융기관 = 권한당국 / DNFBP = 권한당국 **또는 SRB** / VASP = ==**SRB 불가, 권한당국만**== |
| **일회성 거래 기준금액** | 일반 = **15,000** / 전신송금 형태 = **1,000** / 카지노 = **3,000** |
| **인·허가 vs 등록 (권고 26)** | 핵심원칙 적용 금융기관 = **인·허가** / MVTS·환전 = 인·허가 **또는** 등록 |
| **연속지급 vs 보호지급** | 둘 **다** 권고 16 적용. 국내·국외 **모두** 적용 |
| **기술적 이행평가 vs 효과성 평가** | 전자 = 요구사항 **충족 여부 점검** / 후자 = 성과의 **성취 여부·정도 판단** |
| **확인(identify) vs 검증(verify)** | 확인 = 정보를 받는 것 / 검증 = **독립적 출처의 서류로 대조** |
