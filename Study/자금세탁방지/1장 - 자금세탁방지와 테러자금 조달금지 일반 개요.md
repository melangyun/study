# 약어

| 약어      | 원어                                    | 대상                                    |
| ------- | ------------------------------------- | ------------------------------------- |
| **AML** | Anti-Money Laundering                 | 자금세탁 방지 — ==이미 발생한== **범죄수익**의 세탁     |
| **CFT** | Countering the Financing of Terrorism | 테러자금조달 방지 — ==앞으로 벌어질== **테러에 쓰일 자금** |
| **CPF** | Counter Proliferation Financing       | 확산금융 방지 — WMD 개발 자금 (2012년 추가)        |

> [!question] 왜 AML과 CFT는 함께 다닐까?
>목적은 달라도 인프라가 동일하기 때문
>고객확인 (KYC/CDD), 의심거래보고 (STR), 거래 기록 보관 같은 장치는 양쪽에서 그대로 쓰임
>FATF 40개 권고사항, 한국의 특정금융정보법, FIU(금융정보분석원)체계도 마찬가지

# 국제기준에서 자금세탁 정의

`국제자금세탁방지기구` 에서는 자금세탁에 대하여 정의된 <u>비엔나협약(1988)</u>나과 <u>팔레모 협약(2000)</u>을 근거로 한다.

> 범죄수익인 걸 알면서 그 돈을 1. 옮기거나, 2. 숨기거나, 3. 챙겨쓰는것

| 행위       | 핵심                       | 포인트                                                      |
| -------- | ------------------------ | -------------------------------------------------------- |
| 전환·이체    | 출처를 감추거나 범인을 도우려고 돈을 움직임 | **목적이 있어야 성립**<br>-> 불법 출처를 은닉, 가장, 범죄 책임 면하게 할 지원을 목적으로 |
| 은닉·가장    | 재산의 성질·출처·소재·소유권 등을 속임   | 목적 없이 은닉·가장이라는 결과 행위 자체로 성립                              |
| 취득·소유·사용 | 받는 시점에 <u>알면서 챙겨씀</u>    | ==받는 사람== 관점                                             |

# 국제기준에서의 테러자금조달 정의
![[aml_vs_cft_direction.png]]
`UN` 은 <u>테러자금 억제를 위한 국제협악(1999)</u> 에서 테러자금조달의 범죄화와 이에 대한 확인, 탐지, 동결, 몰수에 대해서 정의

```
대중을 협박, 정부나 국제기구가 어떤 행위를 하도록 강요하거나
어떤 행위를 하는 것을 금지하려는 목적으로
무장 충돌의 상황에서 시민이나 적대행위에 가담하지 않는 다른 개인들을 사망하게 하거나 심각한 범죄를 위해 자금이 실제로 이용되는것 요구되지 않아야할 것
```

> 자금을 *제공·모집한 시점*에 이미 범죄가 완성됨
- 우리 법에서 또한 자금·재산의 제공·모집 행위 자체를 처벌하고 실제 사용 여부는 묻지 않음


## FATF

**국제자금세탁방지기구(FATF)**: Financial Action Task Force (금융조치기구/국제 자금세탁 방지기구)
- FATF권고사항은 번호가 매겨진 40개 항목의 고정목록.
- 숫자 40은 고정이지만 내용은 계속 바뀜.
  `40개 권고사항` 이름은 그대로 두고, 아래 붙은 **주석서**를 개정하는 방식
 각 나라가 지켜야할 AML,CFT 체크리스트를 상호평가 때 이 40개를 하나씩 (충족/ 대부분 충족 /부분 충족 / 미충족) 4단계로 채점

**타임라인 - 규제 대상의 확장사**

| 시기    | 트랙       | 갯수  | 확장된것                                                          |
| ----- | -------- | --- | ------------------------------------------------------------- |
| 1989  | 설립       |     | G7 파리 정상회의                                                    |
| 1990  | 제정       | 40개 | 마약 자금세탁 억제                                                    |
| 1996년 | 1차       |     | 전제범죄를 중대범죄 전반으로 확대                                            |
| 2001년 | 특별<br>권고 | 48개 | 9·11 직후 **테러자금조달 8개** 신설 (40과 별도)                             |
| 2003년 | 2차       |     | CDD·실소유자비금융사업자(**DNFBPs, 변호사·회계사·카지노 등**) 편입                  |
| 2004  | 특별<br>권고 | 49개 | 현금휴대반출입 1개 추가 → **40+9** 완성                                   |
| 2012년 | 3차       | 40  | 9개 특별권고 40개 안으로 흡수<br>확산금융 추가, 조세범죄를 전제범죄에 포함<br>RBA를 R.1로 격상 |
| 2019년 | 주석서      |     | R.15 개정 → **VASP·Travel Rule**                                |

> R = Recommendation(권고사항)
> **R.1 = 1번 권고사항**, **R.15 = 15번 권고사항**

### cf) 규제 방식의 두갈래 (RBA)

|                | 방식                             | 문제                    |
| -------------- | ------------------------------ | --------------------- |
| **Rule-based** | 모든 고객·거래에 동일한 규칙 적용            | 자원 낭비. 위험한 곳에 집중이 안 됨 |
| **Risk-based** | 위험을 평가해서 **높으면 강하게, 낮으면 간소하게** | 판단 근거를 스스로 입증해야 함     |
2003년 RBA개념은 여기저기 흩어져있었는데, 12년도 R1(맨 앞 1번으로 끌어 올림)
> 40개중 하나가 아니라 `나머지 39개를 관통하는 대원칙`이라는 선언


# 자금세탁의 특성
![[money_laundering_three_traits.png]]
자금세탁의 주요 특징으로는 `국제범죄성`, `조직범죄성`, `화이트칼라 범죄` 세가지를 들 수 있다.

- **어디서: 국제범죄성**
   한 국가 내에서만 이루어지는 것이 아니고, 금융거래를 통해 금융기관, 무역거래, 전자지갑 등 다양한 수단을 동원하여 2개 국가 이상의 국경을 넘나드는 것을 말한다.
	- 국제적으로 선호되는 자금세탁 경유지
		- 조세 피난처(Tax Haven): 금융 비밀보장 철저, 조세 면제 or 낮은 세율
		- 역외금융센터가 운용되는 국가
		- 자금세탁 방지 등의 체계가 미흡하거나 시행되고 있지 않은 국가
- **누가: 조직범죄성**: 대부분 은밀하게 범죄조직에 의해 진행되는것이 일반적
- **어떻게: 화이트칼라 범죄**
   전문지식과 IT기술 등이 필요한 범죄. 다른 범죄에 비해 간접적으로 국가나 사회에 미치는 피해가 크다.


# 자금세탁의 3단계
세탁기 3동작: `넣고 → 돌리고 → 꺼내 입고`
![[money_laundering_three_stages.png]]
**예치-배치(Placement)**
범죄로 번 현금이 처음 *금융권에 들어오는 순간*
- 주요 사례: 자금 혼합, 외환거래, 금액분할, 대출 등

> ex) 3자 대출상환 형태가 빈번함
> - 범죄수익을 그냥 은행에 입금하면 "이 돈 어디서 났냐"라는 질문을 받는다. 그런데 남의 빚을 갚아주는 형태로 넣으면 그 질문을 피해갈 수 있다.

**은폐-반복(Layering)**
돈과 범죄 사이의 연결고리를 끊는 단계. 계좌, 국가, 자산 형태를 계속 바꿔서 추적을 포기하게 만든다.
- 주요 사례: 허위 사류 작성, 입출금 반복, 국가간 자금이동, 전자자금 이체 증

**합법화-통합(Integration)**
출처를 설명할수 있는 돈이 됐으니 - 추적이 불가능해진 불법자금을 정상적인 금융과 사업활동 등에 투입하여, 합법 재산으로 통합시키는 단계
- 주요 사례: 허위송장발행, 수출가격 조작, 위장회사를 통한 부동산 매각 등

> [!info] 서류상 소득이 발생하는가를 기준으로 볼것
> 전부 서류를 만들어내는 기법.  학자- 기관에 따라 반복 단계로 넣기도 한다.

# 자금세탁방지(AML/CFT)의 글로벌 기본원칙

자금세탁방지 ==규제== 는 `사법제도`, `금융제도`, `국제협력체계` 세 가지의 축으로 이루어진다.
![[aml_three_pillars.png]]
**사법제도: 뺏을 근거를 만든다**
`자금세탁은 범죄다`라고 법에 못박는다. 아무리 의심스러운 돈을 찾아내도 압수할 근거가 없기때문에.

1. 전제범죄 지정
	- 어떤 범죄에서 나온 수익어야 자금세탁죄가 성립하는지 정하는것.
	- FATF는 40개 권고사항을 개정하여 전제범죄를 모든 중대범죄로 그 범위를 확대하도록 의무화 하였다.
2. 몰수-추징
	- `범죄가 이익이 되지 않게 만든다` 가 이 축의 목표

**금융제도: 애초에 못들어오게 막는다.**
- 고객확인의무
- 기록 보존
- 의심거래 보고
- 고액현금거래보고
- 금융정보분석원 (FIU)설치 운영 및 국제협력 등의 의무를 부과한다
> 특이한 점은 국가가 아니라 민간 금융회사에게 그 역할을 맡긴다는점.

**국제협력: 빈틈을 없엔다**
국가간 자금세탁 관련 정보교환, 범죄인 인도, 사법 공조와 같은 제도를 통해 상호 협력 체계를 구축하고 있다.
